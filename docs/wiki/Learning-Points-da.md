# Læringspunkter

| Værktøj | Hvad det gør |
| --- | --- |
| `head()`, `tail()`, `shape`, `columns` | Udforsk en DataFrame: første og sidste rækker, størrelse og kolonnenavne |
| `isna()`, `dropna()` | Find NaN-værdier og fjern rækker med manglende data |
| `df['column']`, `df[['a', 'b']]` | Vælg en eller flere kolonner |
| `.loc[index]` | Læs en række eller en enkelt celle |
| `max()`, `min()`, `idxmax()`, `idxmin()` | Find de største og mindste værdier og hvor de står |
| `sort_values()`, `insert()` | Sortér en tabel og tilføj en beregnet kolonne |
| `groupby()` | Gruppér rækker efter kategori, som en pivottabel i Excel |
