# Learning points

| Tool | What it does |
| --- | --- |
| `head()`, `tail()`, `shape`, `columns` | Explore a DataFrame: first and last rows, size and column names |
| `isna()`, `dropna()` | Find NaN values and remove rows with missing data |
| `df['column']`, `df[['a', 'b']]` | Select one or several columns |
| `.loc[index]` | Read a row or a single cell |
| `max()`, `min()`, `idxmax()`, `idxmin()` | Find the largest and smallest values and where they are |
| `sort_values()`, `insert()` | Sort a table and add a calculated column |
| `groupby()` | Group rows by category, like an Excel pivot table |
